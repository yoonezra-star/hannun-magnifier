# 한눈돋보기 1.0 제품 명세

## 확정 사항

- 앱 이름: 한눈돋보기 - 큰글씨 확대경
- Google Play 카테고리: 도구(Tools)
- 패키지명: `com.yoone.hannunmagnifier`
- 버전: `1.0.2`, versionCode `3`
- 주요 사용자: 작은 글씨를 보기 어려운 중장년·시니어를 포함한 일반 사용자
- 핵심 약속: 앱을 열면 바로, 큰 버튼으로, 서버 전송 없이 확대한다.

## 1.0 포함 기능

- 후면 카메라 즉시 시작, 전면/후면 전환
- 1~10배 디지털 확대, 초확대 바로가기
- 플래시 불빛
- 화면 멈춤과 정지 화면 확인
- 일반·흑백·고대비·반전 보기
- 화면 밝기 조절
- 캡처 이미지 사진 앱 저장
- 보통·크게·아주 크게 글자 설정
- 사용 방법, 개인정보처리방침, 지원 페이지
- Android 하단 적응형 AdMob 배너와 동의/개인정보 설정

## 1.0 제외 기능

- OCR, 글자 읽어주기, 클라우드 업로드, 로그인, 분석 SDK, 주소록
- 건강·의료 안내, 진단, 복약 또는 병원 기능
- ‘광학 현미경’, ‘1000배’처럼 기기 성능을 오해하게 만드는 표현

## 정책 위험과 대응

| 위험 | 대응 |
| --- | --- |
| 카메라 민감 권한 | 앱 핵심 기능에만 사용하고 첫 실행 시 Android 시스템 권한으로 요청 |
| 사진/영상 외부 전송 오해 | 카메라 영상은 기기에서만 처리하며 화면에 안내 |
| 저장소 과다 권한 | Android 10 이상은 MediaStore 사용, 구형 Android에만 저장 권한 제한 |
| 광고 오클릭 | 광고를 확대·멈춤·촬영 버튼과 분리된 화면 맨 아래에 배치, 설정 시 숨김 |
| 실제 광고 자체 클릭 | 기본 빌드는 Google 데모 ID, 실제 ID가 없으면 release 차단 |
| 건강 앱 오분류 | 건강 관련 기능·문구 없음, 카테고리는 Tools |
| 아동 대상 오인 | 성인 일반 사용자용, 아동 대상 디자인·콘텐츠 없음 |
