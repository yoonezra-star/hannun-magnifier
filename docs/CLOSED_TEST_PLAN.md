# 비공개 테스트 기록 계획

## 14일 운영 원칙

1. 15~20명을 초대해 최소 12명보다 여유를 둡니다.
2. 모든 테스터가 같은 opt-in 링크로 참여했는지 첫날 확인합니다.
3. 중간에 opt-out하지 않도록 3일, 7일, 12일째 상태를 확인합니다.
4. 사용 빈도를 인위적으로 만들거나 광고 클릭을 요청하지 않습니다.
5. 테스트 빌드는 데모 광고 ID만 사용합니다.

## 테스터에게 요청할 작업

- 첫 실행 카메라 권한 허용과 거부 후 재시도
- 1배, 3배, 10배에서 작은 글씨 확인
- 플래시가 있는 후면 카메라에서 불빛 사용
- 화면 멈춤 후 다시 보기
- 흑백·고대비·반전 비교
- 사진 저장 후 갤러리 확인
- 글자 크기 세 단계 비교
- 화면 회전, 앱 백그라운드/복귀, 전화 수신 후 복귀

## 프로덕션 액세스 답변에 남길 내용

- 테스터 모집 방법과 실제 인원
- 가장 많이 테스트한 기기/Android 버전
- 받은 피드백 3~5개와 반영한 변경
- 충돌·ANR·권한 거부 시 동작 확인 결과
- 앱이 사용자에게 제공하는 가치와 프로덕션 준비 근거
