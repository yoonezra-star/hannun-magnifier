# 비공개 테스트 피드백 및 반영 기록

## 2026-08-28~29 — 카메라 초기화 및 광고 배치

- 테스트 기기: Samsung SM-N950N, Android 9
- 피드백: 앱 실행 후 `카메라를 준비하고 있습니다` 화면에서 진행되지 않는 현상
- 원인: Android Activity와 Capacitor WebView가 카메라 권한을 중복 요청할 수 있었고, 웹 카메라 초기화에 제한시간이 없어 권한 응답이 멈추면 무한 대기했습니다.
- 반영 내용:
  - Android Activity의 중복 카메라 권한 요청 제거
  - 카메라 초기화 30초 제한시간과 재시도 화면 추가
  - 지연 응답 및 이전 카메라 스트림 정리
  - Android 9 저장공간 권한을 사진 저장 시점에만 요청
  - 실제 광고 높이를 반영해 하단 기능 버튼이 가려지지 않도록 조정
- 검증 결과:
  - 단위 테스트 6개, 린트, 웹 빌드, Android Release 빌드 통과
  - 최초 권한 요청, 후면·전면 전환, 화면 멈춤·복귀, 사진 저장 확인
  - 테스트 광고와 두 번째 기능 버튼 줄이 겹치지 않는 것을 실기기에서 확인
  - 치명적 Android 및 WebView 오류 없음
- 수정 버전: `1.0.1` (`versionCode 2`)

## 2026-08-29 — 초확대 후 카메라 복구

- 피드백: 초확대 또는 카메라 전환 후 실시간 카메라 화면으로 돌아오지 않는 경우가 있어 즉시 복구할 버튼이 필요함
- 원인 및 보완점: 기존 확대값 버튼은 배율만 1배로 바꾸며 카메라 스트림은 다시 시작하지 않아, 스트림이 멈춘 경우 복구 기능이 없었습니다.
- 반영 내용:
  - 확대 조절 아래에 큰 `화면 리셋` 버튼 추가
  - 리셋 시 확대 1배, 밝기 기본값, 일반 보기, 화면 멈춤을 함께 초기화
  - 불빛을 끄고 기존 스트림을 종료한 뒤 후면 카메라를 새로 시작
  - 카메라 전환도 동일한 스트림 정리·재시작 경로를 사용하도록 보강
  - 사용 방법에 화면 리셋 안내 추가
- 검증 결과:
  - 단위 테스트 7개, 린트, 웹 빌드, Android Debug·Release 빌드 통과
  - 390×844 모바일 화면에서 버튼 배치와 기존 기능 버튼 비가림 확인
  - 실제 휴대폰 USB 연결이 없어 이번 수정의 실기기 재검증은 대기 중
- 수정 버전: `1.0.2` (`versionCode 3`)
