# Google Play Console 입력 초안

## 앱 설정

- 앱 또는 게임: 앱
- 무료 또는 유료: 무료
- 카테고리: 도구(Tools)
- 태그 후보: 돋보기, 접근성, 도구
- 고객지원 이메일: **출시 전 실제 공개 이메일 입력 필요**
- 개인정보처리방침 URL: `https://hannun-magnifier.pages.dev/privacy.html`
- 지원 URL: `https://hannun-magnifier.pages.dev/support.html`

## 앱 콘텐츠

- 개인정보처리방침: 있음
- 광고 포함: 예
- 앱 액세스: 모든 기능을 로그인이나 특별한 액세스 없이 이용 가능
- 타겟층: 만 18세 이상
- 아동 대상 앱: 아니요
- 뉴스 앱: 아니요
- 건강 앱: 아니요
- 정부 앱: 아니요
- 금융 기능: 없음
- 사용자 제작 콘텐츠·소셜 기능: 없음

## 콘텐츠 등급 설문 근거

폭력, 성적 콘텐츠, 욕설, 약물, 도박, 공포, 사용자 간 상호작용, 위치 공유, 구매 기능이 없습니다. 광고 포함 여부에는 ‘예’로 답합니다. 최종 등급은 Play Console 설문 결과를 따릅니다.

## 데이터 보안 초안

앱 자체 카메라 영상과 캡처 사진은 기기에서만 처리하므로 ‘수집’으로 신고하지 않습니다. Google Mobile Ads SDK 때문에 아래 데이터는 수집 및 제3자(Google) 공유로 신고하는 보수적 기준을 사용합니다.

| Play 데이터 유형 | 수집 | 공유 | 목적 |
| --- | --- | --- | --- |
| 대략적인 위치(IP 기반) | 예 | 예 | 광고, 분석, 사기 방지·보안·규정 준수 |
| 앱 상호작용 | 예 | 예 | 광고, 분석, 사기 방지·보안·규정 준수 |
| 진단 정보 | 예 | 예 | 분석, 사기 방지·보안·규정 준수 |
| 기기 또는 기타 ID | 예 | 예 | 광고, 분석, 사기 방지·보안·규정 준수 |

- 전송 중 암호화: 예(TLS)
- 사용자 계정 생성: 없음
- 필수/선택: 광고 SDK에서 자동 처리되는 데이터는 필수로 신고
- 데이터 삭제: 앱 설정은 앱 데이터 삭제/제거로 삭제. 광고 ID는 Android 설정에서 재설정·삭제 가능. Console의 최신 문구를 확인해 최종 선택
- 개인정보 선택: 필요한 지역에서는 Google UMP 동의 화면 제공, 앱 설정에 광고 개인정보 설정 버튼 제공

SDK 버전을 올릴 때마다 Google Mobile Ads의 최신 Play 데이터 공개 안내와 이 표를 다시 비교합니다.

## 권한 설명

- `CAMERA`: 실시간 돋보기와 화면 캡처에 필수
- `INTERNET`: AdMob 광고·동의 정보 요청에 사용
- `WRITE_EXTERNAL_STORAGE`(Android 9 이하만): 캡처 사진 저장
- `AD_ID`: Google Mobile Ads SDK가 광고 및 부정 사용 방지에 사용

## 비공개 테스트

- 권장 국가: 대한민국
- 테스트 트랙 이름: `closed-korea-1.0`
- 테스터: 최소 12명보다 여유 있게 15~20명 초대
- 조건: 최소 12명이 14일 연속 opt-in 상태 유지
- 피드백 채널: 이메일 또는 별도 메신저 그룹
- 주요 시나리오: 권한 허용/거부, 확대, 플래시, 정지, 보기모드, 카메라 전환, 사진 저장, 글자 크기, 광고와 버튼 간격
